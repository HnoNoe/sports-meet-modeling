# 问题 1 读题分析：学院合并分组优化模型

> 人设计文档。逐句拆解题意，明确每个设计决策及其理由，为代码实现定调。

## 一、原文

> **问题 1**：如果比赛允许若干学院合并后共同参加比赛，如何设计一个分组数量不低于 12 个组、各组人员总数和男女性别比较为均衡的优化分配模型？并对该分组方案的公平指数进行讨论。

## 二、逐句拆解

### 1. "允许若干学院合并后共同参加比赛"

- **合并单元是学院，不是专业**：一个学院必须整体进入某一组，不能拆散。
  → 决策单元 = 20 个学院。
- "若干"意味着：可以只合并一部分，有的学院仍可单独成组。
  → 允许单学院组存在。

### 2. "分组数量不低于 12 个组"

- K ≥ 12。另一方面 20 个学院最多分出 20 个非空组。
  → **K ∈ {12, 13, …, 20}，K 本身是决策变量**。
- K = 20 即现状（零改动、最不均衡）；K = 12 改动最大、最均衡。
  → 公平与效率（组织变动成本）的权衡是本问的核心讨论点，
    交付 **F-K 权衡曲线**，而不是只给一个 K。

### 3. "各组人员总数和男女性别比较为均衡"

- 两个均衡目标：**组总人数**接近、**组性别比**接近。
- 性别比的度量：各组女生占比 p_k = F_k/S_k 应接近全校女生占比 p̄。
  在总人数均衡的前提下，"女生人数均衡"与"性别比均衡"近似等价，
  且前者与公平指数模块的口径一致 → **目标中用女生人数，报告中换算性别比**。
- 注意题目**没有**要求特长生均衡（那是问题 3 的事）
  → 特长生不进目标函数，但方案产出后要报告各组特长生分布作为参考。

### 4. "对该分组方案的公平指数进行讨论"

- 硬性要求，讨论内容：
  1. 最优方案的 F（各分项 + 综合值）与现状基线（F=0.2392）对比；
  2. 权重敏感性：方案优劣是否随权重翻转；
  3. K 的选择理由（F-K 曲线的拐点分析）。

## 三、数学模型

**集合与参数**

- 学院集合 I = {1,…,20}，组集合 J = {1,…,K}；
- s_i：学院 i 总人数；f_i：学院 i 女生人数；t_i：特长生数（仅报告用）；
- S̄ = Σs_i / K，F̄ = Σf_i / K：组规模的理想均值。

**决策变量**

- x_ij ∈ {0,1}：学院 i 是否分入组 j。

**约束**

```
Σ_j x_ij = 1        ∀i      每个学院恰好进一个组
Σ_i x_ij ≥ 1        ∀j      每组非空
x_ij ∈ {0,1}
```

**目标函数（两阶段设计）**

综合公平指数 F 含基尼/泰尔等非线性项，不能直接进整数规划。
采用**代理目标 + 精修目标**的两阶段法：

- **阶段一（MILP 代理目标，求全局结构）**：

  min  Σ_j |S_j − S̄|  +  μ·Σ_j |F_j − F̄|

  L1 偏差可线性化（引入辅助变量 u_j ≥ ±(S_j−S̄)，v_j ≥ ±(F_j−F̄)），
  用 scipy.optimize.milp（HiGHS）精确求解。μ 为规模-性别权衡系数，
  默认按两队属性标准差之比设定（人设计参数，代码中注明）。

- **阶段二（局部交换精修，对齐真实 F）**：
  以 MILP 解为起点，用真实综合公平指数 F 做目标，
  执行"两学院换组 / 单学院调组"的局部搜索，直到无改进。
  弥补代理目标与真实 F 之间的口径差。

**K 的扫描**：对 K = 12,…,20 各跑一次完整流程，得 F(K) 曲线，
结合"合并学院数量 = 20 − K + 组内合并次数"讨论选取推荐 K。

## 四、算法选型与理由

| 方案 | 结论 | 理由 |
|---|---|---|
| 暴力枚举 | ✗ | S(20,12) 斯特林数，天文数字 |
| 纯启发式（随机重启+局部搜索） | 备选 | 快，但无最优性证明，小尺度浪费 |
| **MILP（HiGHS）+ 局部精修** | ✅ 采用 | 20 单元 × 12~20 组变量规模极小（≤400 个 0-1 变量），可秒级精确求解；阶段二把口径对齐到真实 F |
